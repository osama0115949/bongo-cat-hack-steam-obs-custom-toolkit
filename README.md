## ❓ Troubleshooting

**My Bongo Cat isn't showing up**: Make sure the app is still running in the system tray. If you closed it, just re-open it from the Start menu.

**The auto-clicker isn't working in a specific game**: Some games block simulated input. Try lowering the clicks per second and make sure the game window is active.

**OBS doesn't capture the overlay**: Ensure you've selected "Window Capture" and picked the correct window from the dropdown list. Sometimes you need to restart OBS after generating a scene.

**My clicks are being registered too fast**: Lower your clicks per second in the settings. Start slow and work your way up.
